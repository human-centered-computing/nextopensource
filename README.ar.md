# NextOpenSource

> حالة الترجمة: مسودة بمساعدة الذكاء الاصطناعي، بانتظار مراجعة لغوية بشرية.

[English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [العربية](README.ar.md)

## ما هو NextOpenSource؟

مساحة مستقلة لتقييم البرمجيات مفتوحة المصدر وتكييفها ضمن NextLife ولكل مشاريع HCC. تقارن إعادة الاستخدام ومستودعات Core والتطوير الأصلي، وتوثّق منشأ المصدر وتوافق الترخيص والصيانة والأمن وحدود التكييف.

**الحالة:** مستودع عام ومكتبة Core مشتركة؛ لا توجد خدمة عاملة أو وكلاء منشورون أو ضوابط موافقة آلية.

## الدور ومعايير العمل

يعمل دور **متخصص المصادر المفتوحة** في [NextDeveloper](https://github.com/human-centered-computing/nextdeveloper) هنا بصفة بشرية أو ذكاء اصطناعي أو هجينة ضمن النطاق المصرح به. تبقى المسؤولية البشرية والمراجعة المستقلة والموافقة البشرية إلزامية.

- تسجيل عنوان المصدر الأصلي والإصدار أو الالتزام المثبت والترخيص والإشعارات والصيانة والاعتماديات.
- مقارنة Core القائم والبدائل والإضافات والمحوّلات والتطوير الأصلي، وتقييم التكلفة والمنفعة البشرية.
- حفظ تاريخ المصدر الأصلي ونسبه وتراخيصه، وفصل تعديلات Core عن البيانات المحلية والعرض وقيمة المنتج.
- توثيق الرقع واستراتيجية التحديث والعقود والقيود الأمنية والترخيصية، وإحالة التحقق المستقل إلى NextSecurity.

يتولى NextRoadmap التحليل المعتمد، ويتولى NextOpenSource تقييم المصادر وسجلات منشئها. [مكتبة Core](Core/README.md) هي مكان الاستيراد المشترك المصرح به بمجلد لكل مكون. تظل مستودعات Core والمنتجات المستقلة مسؤولة عن الشفرة المعدلة. لا يُصرح تلقائياً باستنساخ أو إصدار أو ترخيص أو تكامل.

## مساحات المشاريع وسير العمل

- يُستخدم مجلد واحد في المستوى الأعلى لكل معرّف مشروع أو وحدة. يُنشأ عند بدء العمل المصرح به ويُسجّل هنا، وتُحفظ المراجعات اللاحقة داخله؛ لا تُنشأ مجلدات مكررة أو فارغة.
- تُقرأ أولاً دراسة المشروع المعتمدة في [NextRoadmap](https://github.com/human-centered-computing/nextroadmap) وسياسات HCC، ويُستخدم [قالب سجل العمل](templates/WORKSPACE.md).
- يُوثّق النطاق والدور والمسؤول البشري ومراجعة المصدر الدقيقة والأدلة والقرارات والقيود ومعايير القبول والمنفعة البشرية القابلة للقياس والمراجعة المستقلة والموافقة البشرية المطلوبة. تُقدّم التغييرات ضمن طلبات دمج قابلة للمراجعة.
- لا تُحفظ الأسرار أو البيانات الشخصية أو الأدلة السرية في سجل Git العادي؛ تُربط الأدلة المحمية عند التصريح بذلك. لا موافقة ذاتية، ولا توسيع صامت للنطاق، ولا ادعاء بنتائج اختبار بلا دليل.

## مكتبة Core

تضم [Core](Core/README.md) مصادر قابلة لإعادة الاستخدام وسجلات منشئها بعد اعتمادها. أول مكون مسجّل هو [NextID-Core](Core/NextID-Core/README.md)، وهو نسخة دقيقة مثبتة من مصدر Keycloak الأصلي.
