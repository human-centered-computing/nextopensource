[مكتبة Core](../README.ar.md)

أساس مشترك مفتوح المصدر للهوية والوصول في NextID. المصدر [keycloak/keycloak](https://github.com/keycloak/keycloak)، والتفرع الشخصي مرجع هيكلي لا مصدر. لا تغييرات مقصودة في الملفات الأصلية.

- إصدار الأصل: [26.8.2](https://github.com/keycloak/keycloak/releases/tag/26.8.2) (2026-11-05).
- الالتزام المثبت: [`e514445f9dcdabc5bdcf67cab56c1e49655de067`](https://github.com/keycloak/keycloak/commit/e514445f9dcdabc5bdcf67cab56c1e49655de067)
- شجرة المصدر: `6f439a9bda71c39bf725150cea5d50f149e423f6`
- الترخيص: Apache-2.0؛ الترخيص والنسب والإشعارات الأصلية ضمن المصدر.
- المصدر: [source/](source/)، شجرة Git الأصلية الكاملة كملفات عادية.

يحتوي الاستنساخ العادي على كامل شجرة المصدر بلا وحدات فرعية. يمكن بناء NextID من المصدر المثبت؛ تبقى البيانات الموطنة والسمات والإضافات وDockerfile وإعدادات المنتج في مستودعه المستقل.

يضيف NextID الشخصي مستمع NextLog إلى صورة Core. يفصل HCC المصدر الأصلي وقطعة بناء Core المراجعة وصورة المنتج المخصصة. لا يفوض هذا التسجيل البناء أو النشر. سجل التزام NextOpenSource الدقيق وبصمة الصورة ولا تعتمد latest المتغيرة. المستودع عام ولا تضع اعتمادات في Dockerfile.

حدث المصدر فقط بطلب دمج مراجع وتحقق من الشجرة وحفظ التراخيص والإشعارات وتقييم NextSecurity والبناء والانحدار قبل الإنتاج. لا تحديث أو نشر آلي بموجب التسجيل.
